## 管理员端当前边界

本版已经提供知识库管理入口，但尚未提供真实上传按钮和后端文档 API。这样可以先固定权限边界，同时避免使用临时内存数据冒充完成的知识库。

RAG 阶段计划接入：

1. MySQL 保存文档元数据、版本、发布状态和审计信息。
2. ES 保存可检索文本块、关键词字段及向量字段。
3. Redis 保存短期任务状态、限流与热点查询缓存。
4. 管理员上传文档后异步完成解析、切分、索引和发布。
5. 患者 Agent 只检索已发布知识，并在回答中返回引用来源。

## 安全约束

- Agent 不建立患者或管理员账号表，不保存密码。
- Agent 不自行签发或解析 JWT。
- Authorization 不写入日志、MySQL、Redis、ES 或模型上下文。
- 浏览器请求必须经过 Gateway；生产环境不得直接暴露 Agent 的 `8091` 端口。
- 患者接口与管理员接口采用不同 URL 命名空间，并在后端强制校验角色。
- 文档上传、发布和删除等管理写操作后续必须保留审计记录。
