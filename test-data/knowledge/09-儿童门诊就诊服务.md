# 健康医院儿童门诊就诊服务说明

本文档为 Healthy Agent 本地检索测试资料，不代表真实医院政策，也不提供儿科诊断建议。

## 实名就诊

儿童就诊应使用儿童本人的实名信息建档，不得使用家长或其他家庭成员的就诊卡代替。尚未办理身份证的儿童，可按照页面提示使用出生医学证明等有效材料，在人工窗口核验后建档。

## 陪同人员

儿童门诊原则上由一名监护人陪同进入诊室，其他家属在候诊区等候。监护人应准确说明儿童过敏史、既往用药和本次症状变化。需要进行有创操作或签署知情文件时，由医务人员按照规定核验监护关系。

## 发热就诊

儿童出现发热时，应根据医院入口分诊人员指引前往相应区域，不要仅凭知识库自行选择普通门诊。出现意识异常、呼吸困难、持续抽搐等紧急情况时，应立即联系急救服务或前往急诊，由专业人员评估。

## 建议测试问题

- 小孩能不能用家长的就诊卡挂号
- 儿童看诊可以几个家长进诊室
- 没有身份证的孩子怎么建档
