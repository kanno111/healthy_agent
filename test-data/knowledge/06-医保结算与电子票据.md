# 健康医院医保结算与电子票据说明

本文档为 Healthy Agent 本地检索测试资料，不代表真实医院政策。

## 医保结算

患者办理医保结算时，应使用本人有效医保码、社会保障卡或已完成绑定的电子医保凭证。异地就医患者应先确认参保地备案状态；未完成备案或医保网络不可用时，可以先按自费结算，符合条件的患者再按照参保地规定申请手工报销。

## 结算更正

发现结算身份、支付方式或项目明细有误时，应在费用发生后的七个自然日内，携带本人有效身份证件、缴费凭证和相关就诊记录到门诊收费窗口申请核对。已经进入退费流程的账单不能同时办理支付方式更正。

## 电子票据

门诊缴费成功后，电子票据通常在二十四小时内生成。患者可在手机端“电子票据”栏目查看和下载。需要纸质凭证的，可凭票据代码和本人身份信息到自助机打印一次；重复打印件会标注“补打”。电子票据抬头默认使用就诊人姓名，个人医疗票据不支持改为单位名称。

## 建议测试问题

- 异地医保没有备案能不能结算
- 门诊电子发票多久能下载
- 纸质票据可以重复打印吗
