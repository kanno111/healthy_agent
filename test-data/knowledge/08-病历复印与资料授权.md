# 健康医院病历复印与资料授权管理办法

本文档为 Healthy Agent 本地检索测试资料，不代表真实医院政策。

## 可申请人员

患者本人可以申请复印依法允许提供的病历资料。委托他人办理时，需要提供患者和代理人的有效身份证件、患者签署的授权委托书。未成年人由法定监护人申请，并提供能够证明监护关系的材料。

## 申请时间

门诊病历在相关记录完成后可以申请。已出院患者的住院病历通常在出院后十个工作日完成归档，归档前提交的申请会先登记，待资料完整后通知领取。病历尚未归档不等于资料丢失。

## 领取与邮寄

申请人可选择窗口领取或合规邮寄。窗口领取时须出示受理凭证和有效身份证件。邮寄地址提交后如需变更，应在材料寄出前联系病案服务窗口；病历资料不得发送到普通电子邮箱。复印费用按照实际页数收取，邮寄费用另计。
