# 健康医院门诊签到与过号处理规则

本文档为 Healthy Agent 本地检索测试资料，不代表真实医院政策。

## 签到时间

预约患者可在预约时段开始前四十五分钟至结束前十五分钟完成签到。签到渠道包括门诊大厅自助机和手机端。首次就诊或身份信息需要核验的患者，应先到人工服务窗口完成实名核验。上午门诊不支持在下午补签到，下午门诊也不能提前占用上午队列。

## 候诊顺序

签到成功后，系统按照预约时段、签到时间和诊室进度生成候诊顺序。屏幕显示的序号仅用于候诊提示，实际叫号可能因急诊处置、医生临时会诊等情况调整。患者应在对应候诊区等候并留意叫号信息。

## 过号处理

患者被连续呼叫三次仍未到诊室，系统会标记为过号。过号患者应到分诊台重新报到，由护士根据当前候诊人数安排到本时段队列末尾；原预约资格不会立即作废，但不保证按原序号就诊。超过预约时段仍未报到的，由门诊服务中心根据当天号源决定是否安排。

## 建议测试问题

- 最早可以提前多久签到
- 叫号三次没到怎么办
- 过号以后原来的预约还有效吗
