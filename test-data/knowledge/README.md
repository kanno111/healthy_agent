# RAG 检索测试文档

这些资料是专门为 Healthy Agent 本地联调编写的虚构医院规则，不代表任何真实医院政策，也不应作为实际就医依据。

## 使用步骤

1. 使用管理员账号进入“文档与知识库”。
2. 分别上传本目录中的 TXT、Markdown、DOCX 和 PDF 文件（不上传 `evaluation` 子目录）。
3. 为每份文档点击“构建索引”。
4. 进入“向量检索测试”，使用文档末尾的建议问题或换一种说法提问。
5. 检查前几名结果的来源文档、chunk 序号、内容和相关分。

`backend/src/main/resources/evaluation/rag-evaluation-v3.json` 提供 104 条固定评测问题：96 条可回答问题和 8 条无答案或安全负例。编号 01～24 每份测试资料各有 3 条单文档正例；另有 24 条跨制度问题，每题标注 2～3 个确实参与完整回答的相关文档，用于评估多正例 Recall、Precision 和 nDCG。

编号 13～24 不在文档正文附带“建议测试问题”，评测问法只保存在独立数据集中，避免把查询原句直接写入待检索语料。新增文档包含相邻但不等价的流程、例外条件和数字口径，每份实际形成两个 chunk。

当前检索功能会搜索所有已成功构建索引的文档，不包含知识发布状态。管理员可以分别使用 Vector、BM25 和 RRF 策略测试；患者 RAG 仍默认使用 Vector。
