# 向量检索测试文档

这些资料是专门为 Healthy Agent 本地联调编写的虚构医院规则，不代表任何真实医院政策，也不应作为实际就医依据。

## 使用步骤

1. 使用管理员账号进入“文档与知识库”。
2. 分别上传本目录中的 TXT、Markdown、DOCX 和 PDF 文件。
3. 为每份文档点击“构建索引”。
4. 进入“向量检索测试”，使用文档末尾的建议问题或换一种说法提问。
5. 检查前几名结果的来源文档、chunk 序号、内容和相关分。

## 预期区分

| 文档 | 主要主题 | 典型检索意图 |
| --- | --- | --- |
| 01 TXT | 门诊预约、取消、爽约、退款 | 取消挂号后多久退钱 |
| 02 Markdown | 住院探视、陪护、感染防控 | 晚上能否探望住院家属 |
| 03 DOCX | 检验检查、报告领取、隐私验证 | 化验单在哪里下载 |
| 04 PDF | 急诊分诊、危急症状、绿色通道 | 夜间胸痛应去哪里 |

当前检索功能会搜索所有已成功构建索引的文档，不包含知识发布状态。
