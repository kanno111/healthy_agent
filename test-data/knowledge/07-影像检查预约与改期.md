# 健康医院影像检查预约与改期须知

本文档为 Healthy Agent 本地检索测试资料，不构成真实检查或医疗建议。具体检查准备要求必须以医生医嘱和预约单为准。

## 预约确认

完成影像检查缴费后，患者应在手机端或影像预约窗口确认检查日期、报到地点和项目名称。不同检查项目可能位于不同楼层，患者不得仅凭上一次检查地点自行判断。需要特殊准备的项目，以预约单上的个体化说明为准。

## 改期规则

普通预约检查可在原检查时间二十四小时前申请一次免费改期。距离检查不足二十四小时，或者已经完成药品、造影剂等专用物资准备的，应联系影像预约窗口人工评估。改期只变更检查时间，不自动变更医生开具的检查项目。

## 迟到与资料携带

患者应在预约时间前二十分钟到达报到处。迟到超过三十分钟可能需要重新排队或改期。复查患者应携带既往影像资料或提供可查询的检查日期，便于医生进行对比；是否需要空腹、停药或陪同，必须遵循医嘱，知识库不提供个体化判断。

- 做复查要带以前的片子吗
